# 2회차 1교시 학습지 — 집단 비교

## 오늘의 업무 질문

> 「올해 집중 프로그램 참여자의 만족도가 미참여자보다 0.3점쯤 높다. 상사에게 "프로그램 효과가 있다"고 보고해도 될까?」

---

## 1. 먼저 예상하기 (손으로)

두 반의 시험 점수가 있다.

- A반 3명: 70, 80, 90 → 평균 ______
- B반 3명: 75, 85, 95 → 평균 ______
- 평균 차이는 ______점이다. 3명씩만 비교한 이 차이를 「B반이 더 잘 가르친다」의 근거로 쓸 수 있는가? ______

p값: 「실제로는 두 집단에 차이가 없는데, 표본을 뽑다 보니 우연히 이만큼 이상의 차이가 나올 확률」이다. 보통 0.05(5%)보다 작으면 「우연만으로는 잘 안 나오는 차이」로 본다. p값이 작다고 원인이 밝혀지는 것은 아니다.

## 2. AI에게 시키기

```
data/만족도조사.csv에서 프로그램참여(참여/미참여)별로 만족도_전반의 인원, 평균, 중앙값을 구해 줘.
빈칸은 빼고, 몇 명을 뺐는지 알려 줘.
두 집단의 평균 차이가 우연일 가능성을 t검정 p값으로 알려 주고, p값의 뜻을 쉬운 말로 설명해 줘.
평균을 막대그래프로 그려 줘.
```

이어서 다른 요인을 확인한다.

```
참여자와 미참여자의 이용기간_개월 평균도 비교해 줘.
이용기간을 함께 고려하면 참여자와 미참여자의 만족도 차이가 얼마가 되는지, 그 p값은 얼마인지 알려 줘.
```

## 3. 결과 확인 — 검증 3문항

| 확인 | 질문 | 내 답 |
|:---:|---|---|
| ☐ | 표본 수: 참여자 몇 명, 미참여자 몇 명인가? 빈칸은 몇 명 뺐나? | |
| ☐ | 평균 차이와 p값은 얼마인가? | |
| ☐ | 다른 요인: 두 집단의 이용기간은 비슷한가? | |
| ☐ | 이용기간을 함께 고려하면 차이와 p값은 어떻게 바뀌었나? | |
| ☐ | 근거 로그를 열어 숫자를 확인했다 | |
