# 2회차 1교시 학습지 — 독립된 두 집단 비교

## 업무 질문

> 「제안서에서 독거 어르신을 우선 대상으로 삼으려 한다. 독거 어르신의 디지털 역량이 함께 사는 어르신보다 낮다고 쓸 수 있는가?」

자료: `data/욕구조사.csv`. 독거 어르신과 동거 어르신은 서로 다른 사람이다. 이렇게 서로 다른 사람으로 이루어진 두 집단을 비교하는 것을 「독립된 두 집단 비교」라고 한다.

---

## 1. 먼저 예상하기 (손으로)

- A동 어르신 3명의 점수: 2, 3, 4 → 평균 ______
- B동 어르신 3명의 점수: 3, 4, 5 → 평균 ______
- 평균 차이는 ______점이다. 각 동에서 3명을 다시 뽑아도 차이가 1점일까? ______

p값: 「실제로는 두 집단에 차이가 없는데, 표본을 뽑다 보니 우연히 이만큼 이상의 차이가 나올 확률」이다. 보통 0.05보다 작으면 「우연만으로는 잘 나오지 않는 차이」로 본다. p값으로 차이의 크기나 원인을 알 수는 없다.

## 2. AI에게 시키기

평균 비교:

```
data/욕구조사.csv에서 디지털역량_Q1~Q5의 9를 결측으로 바꾸고, 응답한 문항의 평균으로 디지털역량 점수를 만들어 줘.
가구형태가 「독거」인 사람과 나머지(부부·자녀동거)로 나눠 인원, 평균, 표준편차를 구하고,
두 집단의 평균 차이를 독립표본 t검정으로 검정해 줘. p값의 뜻을 쉬운 말로 설명하고 막대그래프를 그려 줘.
```

비율 비교:

```
같은 두 집단(독거, 나머지)의 교육참여의향(있다·모르겠다·없다) 교차표를 만들고,
각 집단 안에서의 비율(행 비율)을 보여 줘. 두 집단의 응답 분포 차이를 카이제곱 검정으로 확인해 줘.
비율마다 분모가 무엇인지 적어 줘.
```

## 4. 제안서 문장 고르기

가장 정확한 문장을 고르고 이유를 적는다.

2. 「독거 어르신의 디지털 역량 평균은 ○점으로 동거 어르신(○점)보다 ○점 낮았으며, 이 차이는 우연으로 보기 어렵다(p = ○).」
