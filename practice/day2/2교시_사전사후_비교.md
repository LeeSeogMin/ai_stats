# 2회차 2교시 학습지 — 같은 참여자의 사전·사후 비교

## 업무 질문

> 「시범 운영한 스마트폰 교실 참여자의 디지털 역량이 8주 뒤 올랐는가? 결과보고서와 다음 제안서의 성과에 무엇이라고 쓸 수 있는가?」

자료: `data/프로그램_사전사후.csv` — 참여자 40명과 대기자 36명이 프로그램 전(사전)과 8주 뒤(사후)에 같은 디지털 역량 5문항에 답했다.

---

## 1. 독립표본과 대응표본

| 구분 | 자료 구조 | 예 | 분석 |
|---|---|---|---|
| 독립된 두 집단 | 두 집단이 서로 다른 사람 | 독거 대 동거 / 참여자의 사후 대 대기자의 사후 | 독립표본 t검정 |
| 같은 참여자의 전후 | 한 사람이 두 번 응답 | 참여자의 사전 대 같은 참여자의 사후 | 대응표본 t검정 |

대응표본 t검정은 사람마다 「사후 − 사전」 변화량을 먼저 구하고, 그 변화량의 평균이 0과 다른지 본다. 사람마다 원래 점수가 달라도 각자의 변화만 보므로, 같은 자료를 독립표본으로 분석할 때보다 작은 변화도 잡아낸다.

## 3. AI에게 시키기

```
data/프로그램_사전사후.csv에서 사전_Q1~Q5의 평균을 「사전」, 사후_Q1~Q5의 평균을 「사후」 점수로 만들어 줘.
사후 응답이 없는 사람(중도탈락)이 몇 명인지 알려 주고, 사전·사후 모두 응답한 사람만 분석해 줘.
참여 집단과 대기 집단 각각에 대해 사전 평균, 사후 평균, 변화량 평균, 대응표본 t검정 p값을 구해 줘.
사람마다 사전에서 사후로 잇는 선 그래프를 집단별로 그려 줘.
```

이어서:

```
참여 집단의 변화량과 대기 집단의 변화량을 비교해 줘. 두 집단은 서로 다른 사람이니 어떤 검정을 써야 하는지 먼저 말하고 검정해 줘.
```

## 4. 틀린 AI 답 찾기

다른 학생이 받은 AI 답이다. 무엇이 틀렸는지 적는다.

> 참여자 38명의 사전 평균은 2.37점, 사후 평균은 2.69점입니다. 사전 점수와 사후 점수를 독립표본 t검정으로 비교한 결과 p값이 0.0642로 0.05보다 큽니다. 따라서 스마트폰 교실은 디지털 역량을 높이는 효과가 없었습니다.
