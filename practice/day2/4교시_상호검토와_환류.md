## 2. 환류: 결과를 다음 단계로 옮기기 (25분)

분석 결과 하나마다 「다음 제안서에 쓸 문장」, 「프로그램 개선안」, 「설문 개선안」을 적는다. 첫 행은 예시다.

| 분석 결과 | 다음 제안서에 쓸 문장(절 이름) | 프로그램 개선안 | 설문 개선안 |
|---|---|---|---|
| 욕구조사에서 가장 어려운 기능은 인터넷뱅킹(○%)과 키오스크(○%) | 사업 필요성: 「지역 어르신 ○명 중 ○%가 …」 | 8주 중 키오스크·인터넷뱅킹 실습 회차를 늘린다 | 기능별 「혼자 할 수 있는가」 문항을 유지한다 |
| 독거 어르신의 역량이 ○점 낮음 | | | |
| 참여자의 사전·사후 변화 ○점, 대기자 ○점 | | | |
| 중도탈락 2명(출석 2~3회) | | | |

AI에게 시켜 보기:

```
outputs/results/분석보고서_내이름.md의 결과를 바탕으로, 내년도 제안서의 「사업 필요성」, 「평가 계획」, 「기대 성과」 절에 넣을 문단을 각각 3문장 이내로 써 줘.
숫자는 보고서에 있는 것만 쓰고, 평가 계획에는 사전·사후 설문과 비교 집단을 넣어 줘.
```

| 확인 | 질문 |
|:---:|---|
| ☐ | AI가 쓴 기대 성과의 숫자가 이번 결과보다 과장되지 않았는가? |
| ☐ | 평가 계획에 측정 시점, 문항, 비교 대상, 분석 방법이 들어 있는가? |
