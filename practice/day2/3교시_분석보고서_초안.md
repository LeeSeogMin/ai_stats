# 2회차 3교시 학습지 — 분석보고서 초안 작성

## 목표

1회차 4교시와 2회차 1·2교시의 분석으로 스마트폰 교실 시범 운영 분석보고서 초안을 쓴다. 틀은 `practice/분석보고서_틀.md`다.

## 보고서 구성

| 절 | 쓰는 내용 | 자주 하는 실수 |
|---|---|---|
| 1. 분석 목적 | 누가 무엇을 결정하려고 이 분석을 하는가 (예: 내년도 제안서의 대상 선정과 성과 근거) | 「현황을 파악하기 위해」처럼 결정과 연결되지 않는 목적 |
| 2. 자료와 분석방법 | 조사 대상·인원·시기, 무응답·중도탈락 처리, 쓴 분석(빈도분석, 기술통계, 독립표본 t검정, 대응표본 t검정, 카이제곱 검정)과 그 분석을 고른 이유 | 인원과 결측 처리를 빼먹음 / 분석 방법 이름만 쓰고 고른 이유를 안 씀 |
| 3. 주요 결과 | 표 1개 이상, 그래프 1개 이상, 숫자에는 분모와 p값 | 평균만 쓰고 인원을 안 씀 / 「유의하다」만 쓰고 차이의 크기를 안 씀 |
| 4. 시사점 | 결과를 근거로 무엇을 바꾸거나 유지할지 | 결과에 없는 내용을 제안 |
| 5. 한계 | 이 자료로 말할 수 없는 것 | 「표본이 적다」 한 줄로 끝냄 |
| 6. 제안서·프로그램 개선에 쓰기 | 다음 제안서에 넣을 문장, 프로그램 개선안, 설문 개선안 | 보고서 결과와 연결되지 않은 개선안 |

## 순서

1. 초안을 시킨다:

```
practice/분석보고서_틀.md 형식으로 스마트폰 교실 시범 운영 분석보고서 초안을 써 줘.
자료는 data/욕구조사.csv와 data/프로그램_사전사후.csv이고, 오늘 실습에서 한 분석(빈도, 기술통계, 독거·동거 비교, 사전·사후 비교, 참여·대기 변화 비교)을 쓴다.
숫자는 모두 실행 로그에서 가져오고, 문장마다 근거 로그를 적어 줘.
「효과가 입증되었다」처럼 단정하는 표현은 쓰지 마.
보고서는 outputs/results/분석보고서_내이름.md로 저장해 줘.
```

2. 검증한다.

| 확인 | 내용 |
|:---:|---|
| ☐ | 보고서의 숫자 5개를 골라 근거 로그에서 찾았다 |
| ☐ | 인원, 무응답, 중도탈락 처리가 「자료와 분석방법」에 적혀 있다 |
| ☐ | 사전·사후 비교에 대응표본 t검정을, 독거·동거와 참여·대기 비교에 독립표본 t검정을 썼다 |
| ☐ | 비율에는 분모가, 차이에는 크기(점수)와 p값이 함께 적혀 있다 |
| ☐ | 시사점이 결과에서 나온다 |
| ☐ | 한계에 대기자 비교, 중도탈락, 자기응답 설문의 한계가 들어 있다 |

3. 내가 직접 고친다: 시사점과 「제안서·프로그램 개선에 쓰기」는 AI 초안을 그대로 두지 말고 내 기관의 사정에 맞게 고친다.

## 단정 표현 고치기

| AI 초안 | 고친 문장 |
|---|---|
| 프로그램이 디지털 역량을 향상시켰다 | 참여자 ○명의 디지털 역량은 사전 ○점에서 사후 ○점으로 ○점 올랐고(대응표본 t검정 p = ○), 같은 기간 대기자 ○명은 ○점 변했다 |
| 독거 어르신은 디지털 역량이 부족하다 | 독거 어르신 ○명의 평균은 ○점으로 동거 어르신 ○명보다 ○점 낮았다(p = ○) |
| 참여자 만족도가 높아 프로그램이 성공적이다 | 참여자 만족도는 평균 ○점(○명 응답)이었다. 만족도는 역량 변화와 따로 측정한 지표다 |
