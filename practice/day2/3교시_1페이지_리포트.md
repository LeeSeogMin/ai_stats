# 2회차 3교시 학습지 — 1페이지 리포트 작성

## 오늘의 목표

내 목적(취업·창업·현재 업무)에 맞는 데이터 하나를 골라 1페이지 리포트를 만든다. 틀은 `practice/report_template.md`다.

## 1. 데이터 고르기

| 내 목적 | 권장 데이터 | 질문 예 |
|---|---|---|
| 재직자(사회복지 등) | `data/만족도조사.csv` | 어느 연령대의 만족도가 낮은가? 시설 만족도와 직원친절 만족도 중 무엇이 더 낮은가? |
| 취업 준비 | `data/채용공고_월급.csv` | 지역·고용형태별 월급 중앙값은 어떻게 다른가? |
| 창업 준비 | `data/가게_월별매출.csv` | 성수기와 비수기의 매출 차이는 얼마인가? 비수기에 광고비를 늘린 달의 매출은? |

내가 고른 데이터: ______________ 내 질문: ______________________________

## 2. 진행 순서

1. 먼저 예상한다: 결과가 어떻게 나올지 한 문장으로 적는다. ______________________
2. AI에게 시킨다:

```
practice/report_template.md 형식으로 1페이지 리포트를 만들어 줘.
데이터: data/○○○.csv / 질문: ○○○
표 1개, 그래프 1개, 결론 3문장, 한계 1문장으로 쓰고, 숫자는 모두 실행 로그에서 가져와.
리포트는 outputs/results/리포트_내이름.md로 저장해 줘.
```

3. 검증한다: 아래 표를 채운다.

| 확인 | 내용 |
|:---:|---|
| ☐ | 리포트의 숫자가 근거 로그에 모두 있다 |
| ☐ | 표본 수와 빈칸 처리가 적혀 있다 |
| ☐ | 비율에는 분모가 적혀 있다 |
| ☐ | 결론이 상관을 인과로 말하지 않는다 |
| ☐ | 한계 문장이 있다 |
| ☐ | 내 예상과 결과를 비교했다 |

4. 고친다: 문장은 내가 직접 고친다. AI가 쓴 결론 중 단정하는 표현(「입증되었다」, 「효과가 있다」)은 근거에 맞게 바꾼다.
