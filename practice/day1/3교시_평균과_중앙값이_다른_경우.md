# 1회차 3교시 학습지 — 평균과 중앙값이 다른 경우

## 오늘의 업무 질문

> 「사회복지 분야 채용공고의 평균 월급이 300만 원이라고 한다. 신입인 나도 300만 원 정도를 기대해도 될까?」

---

## 1. 먼저 예상하기 (손으로)

공고 5건의 월급이 230, 240, 250, 260, 1,000만 원이다.

- 평균 = (230 + 240 + 250 + 260 + 1000) ÷ 5 = ______
- 중앙값 = ______
- 5건 중 평균보다 많이 주는 공고는 몇 건인가? ______
- 1,000만 원 한 건 때문에 평균이 중앙값보다 얼마나 커졌나? ______

이제 `data/채용공고_월급.csv`(200건)를 예상해 본다.

- 평균과 중앙값 중 어느 쪽이 더 클까? ______
- 평균보다 많이 주는 공고는 절반쯤일까, 훨씬 적을까? ______

## 2. AI에게 시키기

```
data/채용공고_월급.csv에서 월급_만원의 평균, 중앙값, 최솟값, 최댓값을 구해 줘.
평균보다 많이 주는 공고가 몇 %인지, 직무별 중앙값도 알려 줘.
월급 분포를 히스토그램으로 그리고 평균과 중앙값을 선으로 표시해 줘.
```
