# 1회차 1교시 학습지 — AI 도구 사용법과 현장 업무 흐름

## 앞 20분: AI 도구 준비

수업 30분 전 조교 지원 시간에 2번(확장 설치)을 마친 학생은 3번부터 한다.

### 1. 실습 폴더 열기

VS Code → 파일 → 폴더 열기 → `ai_stats` 폴더(Windows `C:\ai_stats`, macOS 홈 폴더의 `ai_stats`). 「작성자를 신뢰하십니까?」가 뜨면 「예」를 누른다.

### 2. 확장 설치

오른쪽 아래 「권장 확장」 알림에서 설치를 누른다. 알림이 없으면 왼쪽 확장 아이콘(네모 네 개)을 누르고 검색창에 `@recommended`를 입력해 목록의 확장을 설치한다.

| 확인 | 확장 | 용도 |
|:---:|---|---|
| ☐ | Korean Language Pack | 메뉴를 한국어로 바꾼다(설치 후 재시작) |
| ☐ | GitHub Copilot Chat | 기본 AI 도구 |
| ☐ | Claude Code | 권장 AI 도구(Claude Pro 가입자) |
| ☐ | Python | Python 실행 |
| ☐ | Office Viewer | 엑셀·워드 파일 보기 |
| ☐ | vscode-pdf | PDF 보기 |
| ☐ | HWP Viewer | 한글(hwp·hwpx) 파일 보기 |
| ☐ | Rainbow CSV | CSV 파일의 열을 색으로 구분해 보기 |
| ☐ | Data Wrangler | 표 자료를 엑셀처럼 훑어보기 |

### 3. 로그인

- Copilot: 왼쪽 아래 사람 모양 아이콘 → GitHub로 로그인. 채팅 창을 열고 아래쪽 모드에서 에이전트(Agent)를 고른다. 에이전트 모드에서만 AI가 파일을 만들고 코드를 실행한다.
- Claude Code(Pro 가입자): Claude 아이콘을 누르고 안내에 따라 로그인한다.

### 4. 첫 질문과 근거 확인

채팅 창에 붙여 넣는다.

```
data 폴더에 어떤 파일이 있는지, 각 파일이 몇 행인지 알려 줘.
```

| 확인 | 내용 |
|:---:|---|
| ☐ | AI의 답 끝에 `근거: outputs/results/....log`가 있다 |
| ☐ | 그 로그 파일을 열어 AI가 말한 행 수가 로그에 그대로 있는 것을 확인했다 |

AI가 근거 로그 없이 숫자를 말하면 「그 숫자를 실행 로그로 보여 줘」라고 다시 시킨다.

## 뒤 30분: 기획에서 환류까지

### 5. 시나리오

> ○○종합사회복지관은 내년도 공모사업에 「어르신 디지털 역량 강화 프로그램(스마트폰 교실, 8주)」 제안서를 낸다.
> 올해 지역 어르신 300명에게 욕구조사를 했고, 시범 운영한 스마트폰 교실의 참여자 40명과 대기자 36명에게 사전·사후 설문을 했다.
> 담당자인 나는 ① 제안서의 사업 필요성과 평가 계획을 쓰고, ② 시범 운영 결과를 분석해 보고하고, ③ 결과에 따라 프로그램과 설문을 고쳐야 한다.

자기 기관의 프로그램으로 바꾸고 싶으면 아래 표를 자기 프로그램으로 채운다.

### 6. 목적 → 성과지표 → 측정 문항 연결표

제안서의 평가 계획은 「무엇이 달라지면 성공인가」를 숫자로 적는 것에서 시작한다. 첫 행은 예시다.

| 사업 목적(무엇을 바꾸려 하나) | 성과지표(무엇을 숫자로 보나) | 측정 방법·문항 | 측정 시점 | 비교 대상 |
|---|---|---|---|---|
| 어르신이 스마트폰으로 일상 업무를 혼자 처리한다 | 디지털 역량 점수(5문항 평균, 1~5점)의 사전 대비 사후 변화 | 디지털 역량 5문항(전화·문자, 사진, 카카오톡, 키오스크, 인터넷뱅킹) | 사전·사후 | 같은 참여자의 사전 점수, 대기자의 변화 |
| | | | | |
| | | | | |

AI에게 시켜 보기:

```
위 시나리오의 스마트폰 교실 제안서에 넣을 성과지표를 3개 제안해 줘.
각 지표마다 측정 문항 예시, 측정 시점, 비교 대상을 표로 정리해 줘.
```

| 확인 | 질문 | 내 답 |
|:---:|---|---|
| ☐ | AI가 제안한 지표 중 설문으로 측정할 수 없는 지표가 있는가? | |
| ☐ | 「만족도」만으로 프로그램 성과를 말할 수 있는가? 무엇이 더 필요한가? | |

## 생각해 볼 질문

1. 욕구조사 결과는 제안서의 어느 절에 들어가는가? 사전·사후 결과는 어느 절에 들어가는가?
2. 사전 설문 없이 사후 설문만 하면 성과에 대해 무엇을 말할 수 없는가?
