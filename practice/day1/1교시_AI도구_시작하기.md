# 1회차 1교시 학습지 — AI 도구 시작하기

## 오늘의 목표

- VS Code에 수업용 확장을 설치한다.
- GitHub Copilot(기본)과 Claude Code(Claude Pro 가입자)에 로그인하고 첫 질문을 해 본다.
- AI의 답을 실행 기록(로그)으로 확인하는 방법을 익힌다.

---

## 1. 실습 폴더 열기

1. VS Code를 실행한다.
2. 파일 → 폴더 열기 → `ai_stats` 폴더를 고른다. (Windows `C:\ai_stats`, macOS 홈 폴더의 `ai_stats`)
3. 「이 폴더의 파일 작성자를 신뢰하십니까?」가 뜨면 「예, 작성자를 신뢰합니다」를 누른다.

## 2. 확장 설치

오른쪽 아래에 「이 저장소에 권장 확장이 있습니다」 알림이 뜨면 설치를 누른다. 알림이 없으면 왼쪽 세로 막대의 확장 아이콘(네모 네 개)을 누르고, 검색창에 `@recommended`를 입력해 「작업 영역 권장 사항」의 확장을 하나씩 설치한다.

설치한 뒤 체크한다.

| 확인 | 확장 | 무엇을 하나 |
|:---:|---|---|
| ☐ | Korean Language Pack | 메뉴를 한국어로 바꾼다. 설치 후 오른쪽 아래 「Change Language and Restart」를 누른다 |
| ☐ | GitHub Copilot Chat | 기본 AI 도구 |
| ☐ | Claude Code | 권장 AI 도구 (Claude Pro 가입자) |
| ☐ | Python | Python 코드 실행 |
| ☐ | Office Viewer | 엑셀·워드·파워포인트 파일 보기 |
| ☐ | vscode-pdf | PDF 파일 보기 |
| ☐ | HWP Viewer | 한글(hwp·hwpx) 파일 보기 |
| ☐ | Rainbow CSV | CSV 파일의 열을 색으로 구분해 보기 |
| ☐ | Data Wrangler | 표 데이터를 엑셀처럼 훑어보기 |

확인: 왼쪽 탐색기에서 `data/이용자명부_원본.xlsx`를 눌러 엑셀 표가 보이는지, `lecture/day1.pdf`를 눌러 PDF가 보이는지 확인한다.

## 3. AI 도구 로그인

GitHub Copilot

1. 왼쪽 아래 사람 모양 아이콘 → GitHub로 로그인 → 브라우저에서 승인한다.
2. 위쪽 가운데 Copilot 아이콘(또는 보기 → 채팅)을 눌러 채팅 창을 연다.
3. 채팅 창 아래의 모드에서 에이전트(Agent)를 고른다. 에이전트 모드여야 AI가 파일을 만들고 코드를 실행할 수 있다.

Claude Code (Claude Pro 가입자)

1. 왼쪽 세로 막대 또는 편집기 오른쪽 위의 Claude 아이콘을 누른다.
2. 로그인 안내에 따라 Claude 계정으로 로그인한다.

## 4. 첫 질문

채팅 창에 아래 문장을 그대로 붙여 넣는다.

```
이 폴더의 AGENTS.md를 읽고, 이 폴더에서 네가 지켜야 할 규칙을 5줄로 요약해 줘.
```

AI가 「한국어로 답한다」, 「분석 코드는 outputs/code에 저장하고 run_and_capture.py로 실행한다」 같은 규칙을 말하면 정상이다.

이어서 붙여 넣는다.

```
data 폴더에 어떤 파일이 있는지, 각 파일이 몇 행인지 알려 줘.
```

AI가 코드를 실행해도 되는지 물으면 내용을 읽고 허용(Continue / Allow)을 누른다.

## 5. 하네스 확인

1. AI의 답 끝에 `근거: outputs/results/....log`가 있는지 본다.
2. 왼쪽 탐색기에서 그 로그 파일을 연다. AI가 말한 행 수가 로그에 그대로 있는지 확인한다.
3. 채팅 창에 입력한다: `하네스 돌려서 확인해 줘`
4. 마지막 줄이 `HARNESS_PASS`인지 확인한다.

| 확인 | 내용 |
|:---:|---|
| ☐ | AI의 답에 근거 로그 경로가 있다 |
| ☐ | 로그 파일의 숫자와 AI가 말한 숫자가 같다 |
| ☐ | 하네스 결과가 `HARNESS_PASS`다 |

## 생각해 볼 질문

1. AI가 근거 로그 없이 숫자를 말했다면, 그 숫자를 믿어도 되는가? 무엇을 시켜야 하는가?
2. `AGENTS.md`의 규칙을 AI가 지키지 않을 수도 있다. 지켰는지는 무엇으로 확인하는가?
