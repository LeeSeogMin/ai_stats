## 실습 B. 만족도 평균은 좋은 점수인가

### 1. 먼저 예상하기 (손으로)

이용자 5명의 만족도가 5, 5, 4, 4, 1점이다.

- 평균 = (5 + 5 + 4 + 4 + 1) ÷ 5 = ______
- 중앙값(크기순으로 줄 세웠을 때 가운데 값) = ______
- 5명 중 1명은 1점(매우 불만)이다. 평균만 보고 이 사람을 알아챌 수 있는가? ______

이제 `data/만족도조사.csv`(300명)를 예상해 본다.

- 평균은 4.1점 근처일 것이다. 중앙값은 몇 점일까? ______
- 1~2점(불만)인 사람은 몇 %쯤일까? ______

### 2. AI에게 시키기

```
data/만족도조사.csv에서 만족도_전반의 평균, 중앙값, 점수별 인원과 비율을 구해 줘.
빈칸인 응답은 몇 명인지 알려 주고 빼고 계산해.
점수 분포를 막대그래프로 그려 줘.
작년 평균은 4.3점이었다(data/README.md). 올해와 비교해 줘.
```

### 3. 결과 확인 — 검증 3문항

| 확인 | 질문 | 내 답 |
|:---:|---|---|
| ☐ | 표본 수: 전체 몇 명 중 몇 명의 응답으로 계산했나? | |
| ☐ | 분모: 「1~2점이 ○%」의 분모는 전체 인원인가, 응답한 인원인가? | |
| ☐ | 비교: 작년보다 높은가, 낮은가? 몇 점 차이인가? | |
| ☐ | 근거 로그를 열어 AI가 말한 평균이 로그에 있는지 확인했다 | |
