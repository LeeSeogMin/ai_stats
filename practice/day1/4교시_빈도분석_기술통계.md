## 업무 질문

> 「제안서의 사업 필요성에 지역 어르신의 디지털 이용 실태를 숫자로 적어야 한다. 욕구조사 300명의 결과를 어떻게 요약하나?」

자료: `data/욕구조사.csv` (열 설명은 `data/README.md`)

---

## 1. 먼저 예상하기 (손으로)

어르신 5명의 「카카오톡으로 대화할 수 있다」 응답이 4, 2, 9, 3, 5다. 9는 무응답 코드다.

- 9를 숫자로 그대로 넣은 평균 = (4 + 2 + 9 + 3 + 5) ÷ 5 = ______
- 9를 빼고 응답한 4명의 평균 = ______
- 「4점 이상 응답 비율」을 5명 기준으로 내면 ______%, 응답한 4명 기준으로 내면 ______%

어르신 5명의 한 달 복지관 이용 횟수가 2, 3, 3, 4, 20회다.

- 평균 = ______회, 중앙값 = ______회. 어느 쪽이 「보통 어르신」의 이용 횟수에 가까운가? ______

## 2. AI에게 시키기

자료 정리:

```
data/욕구조사.csv의 디지털역량_Q1~Q5에서 무응답 코드 9가 문항별로 몇 개인지 세어 줘.
9를 결측으로 바꾸고, 5문항 중 응답한 문항의 평균으로 「디지털역량」 점수를 만들어 줘.
원본 파일은 고치지 마.
```

빈도분석:

```
성별, 연령대, 가구형태, 교육수준, 스마트폰보유, 가장어려운기능, 교육참여의향의 빈도표를 만들어 줘.
인원과 비율(%)을 함께 쓰고, 비율의 분모가 몇 명인지 적어 줘.
가장어려운기능은 막대그래프로 그려 줘.
```

기술통계:

```
디지털역량 Q1~Q5 각 문항과 디지털역량 점수의 응답 수, 평균, 중앙값, 표준편차를 표로 만들어 줘.
문항별 평균을 막대그래프로 그려 줘.
```
