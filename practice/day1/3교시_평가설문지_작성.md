# 1회차 3교시 학습지 — 평가 설문지 작성

## 목표

1교시의 연결표에 맞춰 스마트폰 교실의 사전·사후 평가 설문지를 만든다. 틀은 `practice/설문지_틀.md`다. 자기 기관의 프로그램으로 바꿔 작성해도 된다(실제 응답 자료는 쓰지 않는다).

## 작성 원칙

| 원칙 | 이유 |
|---|---|
| 사전과 사후에 같은 문항, 같은 척도를 쓴다 | 문항이나 척도가 바뀌면 점수 변화가 프로그램 때문인지 문항 때문인지 구별할 수 없다 |
| 응답자마다 익명 연결 코드를 받는다(예: 태어난 달 2자리 + 전화번호 끝 2자리) | 같은 사람의 사전·사후를 짝지어야 대응표본 분석을 할 수 있다. 이름은 받지 않는다 |
| 성과 문항은 5단계 척도로 쓴다 | 2단계(예·아니오)로는 「조금 나아진 사람」의 변화가 보이지 않는다 |
| 만족도 문항은 사후에만 넣는다 | 사전에는 만족도를 물을 경험이 없다 |
| 응답자 정보는 분석에 쓸 것만 묻는다 | 문항이 길면 어르신의 응답 부담이 커지고 무응답이 늘어난다 |

디지털 역량 문항의 척도 예: ① 전혀 못 한다 ② 도움이 많이 필요하다 ③ 도움이 조금 필요하다 ④ 대체로 혼자 한다 ⑤ 혼자 잘 한다

## 순서

1. 설문지 초안을 쓴다(15분): `practice/설문지_틀.md`를 복사해 `outputs/results/설문지_내이름.md`로 저장하고 채운다.
2. AI에게 검토시킨다.

```
outputs/results/설문지_내이름.md의 설문 문항을 검토해 줘.
2교시의 네 기준(명확성·중립성·이중질문·응답척도)으로 문항마다 결함이 있는지 보고,
사전·사후 문항과 척도가 같은지, 1교시 연결표의 성과지표를 모두 측정하는지도 확인해 줘.
고칠 문항은 고친 이유와 함께 표로 보여 줘. 파일은 아직 고치지 마.
```

3. 짝과 바꿔 읽는다(10분): 짝의 설문지에서 결함 1개 이상을 찾아 적어 준다.
4. 고친다: AI 검토와 짝 검토 가운데 받아들인 것만 반영하고, 설문지 끝 「수정 기록」 표에 적는다.

## 확인

| 확인 | 질문 |
|:---:|---|
| ☐ | 연결표의 성과지표마다 측정 문항이 하나 이상 있다 |
| ☐ | 사전·사후 문항과 척도가 같다 |
| ☐ | 익명 연결 코드 문항이 있고, 이름·연락처는 받지 않는다 |
| ☐ | 이중질문이 없다 |
| ☐ | 선택지가 겹치거나 빠진 범주가 없다 |
| ☐ | 수정 기록에 고친 문항과 이유가 적혀 있다 |
