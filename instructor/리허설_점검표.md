# Windows·macOS 리허설 점검표 (강사·조교용, 학생 zip에 넣지 않음)

목적: 학생에게 zip을 보내기 전(마감 2026-12-14)에, 깨끗한 컴퓨터에서 설치부터 실습까지 학생과 같은 순서로 돌려 본다.
이 Mac에서는 Windows 스크립트를 한 번도 실행하지 못했다. 아래 W 항목이 통과하기 전에는 zip을 보내지 않는다.

결과를 적는 법: 각 항목에 통과/실패와 날짜를 적고, 실패하면 맨 아래 「실패 기록」에 화면 캡처 경로와 함께 남긴다. 고친 뒤에는 처음부터 다시 실행한다.

| ☐ | `설치가이드.pdf`를 같은 메일에 첨부 |

## 1. 시험 환경

가능한 만큼 준비한다. 위에서부터 중요하다.

| 환경 | 왜 | 준비 |
|---|---|---|
| W1 깨끗한 Windows 11 | 기본 경로 | 가상머신 또는 새 사용자 계정. VS Code만 설치 |
| W2 사용자 이름이 한글인 Windows 계정 | 한글 경로 문제 (`C:\Users\홍길동`) | 새 로컬 계정을 한글 이름으로 만든다 |
| W3 스마트 앱 컨트롤이 켜진 Windows 11 | 패키지 import 차단 문제 | 새로 설치한 Windows 11에서만 켜질 수 있다. 상태 확인 명령은 아래 |
| W4 회사 노트북(보안 프로그램 설치됨) | 다운로드·실행 차단 | 조교·지인의 업무용 노트북 |
| W5 바탕화면·문서가 OneDrive와 동기화된 Windows | OneDrive 경고 문구 확인 | OneDrive 로그인된 계정 |
| M1 macOS 새 사용자 계정 | 기본 경로 | VS Code만 설치(응용 프로그램 폴더) |

스마트 앱 컨트롤 상태 확인 (PowerShell, 값이 1이면 켜짐):

```powershell
Get-ItemProperty HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy | Select-Object VerifiedAndReputablePolicyState
```

## 4. 실습 전 과정 (Copilot 1회, Claude Code 1회)

학습지의 질문 문장을 그대로 붙여 넣고, 결과를 `instructor/정답표.md`와 대조한다. 숫자가 다르면 빈칸·분모·중복 처리 기준이 다른지 먼저 본다.

| 확인 | 교시 | 정답표와 대조할 값 | 걸린 시간 | Copilot | Claude |
|:---:|---|---|---|---|---|
| ☐ | 1-2 실습 A 명부 정리 | 40행 → 37행, 중복 3행 | | | |
| ☐ | 1-2 실습 B 만족도 | 응답 288명, 평균 4.11, 중앙값 4, 1~2점 11.1% | | | |
| ☐ | 1-3 월급 | 평균 305.1, 중앙값 260.0, 평균 이상 8.0% | | | |
| ☐ | 1-4 틀린 답 5개 | 학생 입장에서 50분 안에 5개를 찾을 수 있는지 | | — | — |
| ☐ | 2-1 집단 비교 | 차이 0.31, p 0.0131 / 이용기간 고려 0.25, p 0.0867 | | | |
| ☐ | 2-2 광고·매출 | 상관 0.85, 기울기 9.08 → 성수기 고려 -0.28(p 0.623) | | | |
| ☐ | 2-2 교차표 | 행 비율 참여 88.2%·미참여 81.1%, p 0.1234 | | | |
| ☐ | 2-3 리포트 | `outputs/results/리포트_*.md` 생성, 숫자가 로그에 있음 | | | |
| ☐ | 모든 그래프 | 한글이 네모(□)로 나오지 않음 | | | |
| ☐ | 마지막에 하네스 | `HARNESS_PASS` | | | |

시간 판단: 1회차 2교시(실습 A+B)가 50분을 넘으면 실습 A를 「AI가 고친 목록 확인」만 하도록 줄인다.
