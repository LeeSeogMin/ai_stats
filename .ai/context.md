> 작업을 시작할 때 이 파일과 루트 `AGENTS.md`를 먼저 읽는다.

## 이 폴더는 무엇인가

- 「AI를 활용한 통계」 특강(2026-12-21, 12-23) 실습 폴더
- 학생이 한국어로 질문하면 AI가 분석 코드를 만들어 실행하고, 학생은 결과를 검증한다

## 폴더 구성

| 경로 | 내용 |
|------|------|
| `lecture/` | 회차별 강의원고(PDF 포함). 수정하지 않는다 |
| `practice/` | 교시별 학습지와 1페이지 리포트 틀 |
| `data/` | 교육용 가상 데이터. 원본은 수정하지 않는다 |
| `outputs/code/` | AI가 만든 분석 코드 |
| `outputs/results/` | 실행 로그·증거 파일·그래프 |
| `scripts/` | 하네스 도구(`run_and_capture.py`, `harness.py`) |
| `.claude/skills/` | 수업용 스킬(PDF·HWPX 변환 등) |
