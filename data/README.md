# 실습 데이터

모든 파일은 수업을 위해 만든 교육용 가상 데이터다. 실제 사람·기관·가게와 관계가 없다.
원본 파일은 수정하지 않는다. 정리한 데이터는 `outputs/results/`에 새 파일로 저장한다.

| 파일 | 쓰는 교시 | 행 수 | 내용 |
|---|---|---:|---|
| `이용자명부_원본.xlsx` | 1회차 2교시 | 40 | 복지관 프로그램 이용자 명부를 손으로 옮겨 적은 기록. 날짜·만족도 표기가 섞여 있고 중복 입력이 있다 |
| `만족도조사.csv` | 1회차 2교시, 2회차 1·2교시 | 300 | 복지관 이용자 만족도 조사. 만족도는 1(매우 불만)~5(매우 만족)점 |
| `채용공고_월급.csv` | 1회차 3교시 | 200 | 사회복지·사무 분야 채용공고의 월급 |
| `가게_월별매출.csv` | 2회차 2교시 | 36 | 동네 카페의 2024-01~2026-12 월별 광고비와 매출 |

## 열 설명

`만족도조사.csv`

| 열 | 뜻 |
|---|---|
| 응답자ID | R001~R300 |
| 성별, 연령대 | 응답자 특성 |
| 이용기간_개월 | 복지관을 이용한 기간(개월) |
| 프로그램참여 | 올해 집중 프로그램에 참여했는지(참여/미참여) |
| 만족도_전반 | 전반적 만족도(1~5점). 응답하지 않은 칸은 비어 있다 |
| 만족도_직원친절, 만족도_시설 | 항목별 만족도(1~5점) |
| 재이용의향 | 다시 이용할 생각이 있는지(예/아니오) |

비교 기준: 이 복지관의 작년 같은 조사에서 전반적 만족도 평균은 4.3점이었다(가상).

`채용공고_월급.csv`: 공고ID, 직무, 지역, 고용형태, 월급_만원(세전 월급, 만 원)

`가게_월별매출.csv`: 연월, 성수기(7·8·12월이면 「예」), 광고비_만원, 매출_만원
