# 실습 자료

모든 파일은 수업을 위해 만든 교육용 가상 자료다. 실제 사람·기관과 관계가 없다.
원본 파일은 수정하지 않는다. 정리한 자료는 `outputs/results/`에 새 파일로 저장한다.

시나리오: ○○종합사회복지관 어르신 디지털 역량 강화 프로그램(스마트폰 교실, 8주)

| 파일 | 쓰는 교시 | 행 수 | 내용 |
|---|---|---:|---|
| `욕구조사.csv` | 1회차 4교시, 2회차 1교시 | 300 | 프로그램 기획 단계에 지역 65세 이상 어르신에게 한 디지털 이용 욕구조사 |
| `프로그램_사전사후.csv` | 2회차 2교시 | 76 | 시범 운영 참여자 40명과 대기자 36명의 사전·사후 설문 |

## 디지털 역량 5문항 (두 파일 공통)

| 문항 | 내용 |
|---|---|
| Q1 | 전화를 걸고 문자를 보낼 수 있다 |
| Q2 | 사진을 찍어 다른 사람에게 보낼 수 있다 |
| Q3 | 카카오톡으로 대화할 수 있다 |
| Q4 | 무인주문기(키오스크)로 주문할 수 있다 |
| Q5 | 인터넷뱅킹으로 돈을 보낼 수 있다 |

척도: 1 전혀 못 한다, 2 도움이 많이 필요하다, 3 도움이 조금 필요하다, 4 대체로 혼자 한다, 5 혼자 잘 한다.
디지털 역량 점수는 다섯 문항의 평균(1~5점)이다.

## `욕구조사.csv` 열

| 열 | 뜻 |
|---|---|
| 응답자ID | N001~N300 |
| 성별, 연령, 연령대 | 응답자 특성 (연령대: 65~69세, 70~74세, 75~79세, 80세 이상) |
| 가구형태 | 독거 / 부부 / 자녀동거 |
| 교육수준 | 초졸 이하 / 중졸 / 고졸 이상 |
| 스마트폰보유 | 예 / 아니오 |
| 가장어려운기능 | 스마트폰으로 하기 가장 어려운 기능 하나 |
| 디지털역량_Q1~Q5 | 위 다섯 문항(1~5점). 9는 무응답 코드다 |
| 교육참여의향 | 디지털 교육이 열리면 참여할 생각이 있는지(있다 / 모르겠다 / 없다) |

## `프로그램_사전사후.csv` 열

| 열 | 뜻 |
|---|---|
| ID | 참여자 P01~P40, 대기자 W01~W36 |
| 집단 | 참여 / 대기(같은 기간 프로그램을 기다린 신청자) |
| 성별, 연령 | 응답자 특성 |
| 사전_Q1~Q5 | 프로그램 시작 전 디지털 역량 문항 |
| 사후_Q1~Q5 | 8주 뒤 같은 문항. 중도탈락자는 비어 있다 |
| 출석회차 | 8회 중 출석한 횟수(대기자는 0) |
| 만족도 | 프로그램 만족도(1~5점, 참여자 사후에만) |
